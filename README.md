# Hibernate RPG Admin Panel

##### This project is a reimplementation of the RPG admin panel backend, replacing the in-memory map storage with MySQL + Hibernate for real-world database handling.

## Features

Uses Hibernate with MySQL instead of in-memory storage.

Player entity mapped to rpg.player table with correct constraints.

Uses NativeQuery and NamedQuery for learning different query types in Hibernate.

Includes pagination for listing players.

Includes p6spy logging to see executed SQL queries in the console.
